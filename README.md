## Deskripsi Karya
SiberAman adalah platform edukasi interaktif berbasis web yang dirancang untuk meningkatkan kesadaran masyarakat, khususnya generasi muda dan mahasiswa, terhadap ancaman kejahatan siber yang semakin marak di Indonesia. Platform ini mengangkat subtema **Keamanan Siber & Literasi Digital**, dengan menyajikan konten edukatif seputar serangan siber seperti *phishing*, *malware*, *social engineering*, dan *web vulnerability* secara interaktif dan mudah dipahami.

Tujuan utama proyek ini adalah menjadi jembatan literasi digital bagi pengguna awam agar mampu mengenali, mencegah, dan merespons ancaman siber secara mandiri. Manfaat yang dihadirkan meliputi peningkatan kesadaran keamanan digital, panduan praktis perlindungan akun dan data pribadi, serta katalog ancaman siber lengkap dengan langkah mitigasinya. Proyek ini dibangun menggunakan teknologi web modern — React.js dan Tailwind CSS — untuk memastikan tampilan yang responsif di berbagai perangkat.
